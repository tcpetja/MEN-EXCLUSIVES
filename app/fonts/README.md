# Fonts

Self-hosted variable fonts, Latin subset, served through `next/font/local`.

- **Noto Serif Display** (weight 100–900, width 62.5–100 %), roman and italic. SIL Open Font License 1.1.
- **Archivo** (weight 100–900, width 62–125 %). SIL Open Font License 1.1.

Files were taken from the `@fontsource-variable/noto-serif-display` and
`@fontsource-variable/archivo` packages (the `latin-standard` builds).
